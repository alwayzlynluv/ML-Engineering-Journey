# ✍️ Handwriting Recognition (EMNIST)

This project features a Deep Learning model designed to classify handwritten letters. It achieved **1st Place** in a class design competition with a verified test accuracy of **93.4%**.

---

## 🏆 Achievement Highlights
* **Rank:** 1st Place (Class Competition)
* **Accuracy:** 93.4% on hidden test data
* **Dataset:** EMNIST (Letters)

## 🛠️ Technical Strategy
To reach high accuracy while keeping the model efficient, I focused on:
* **CNN Architecture:** A custom Convolutional Neural Network designed to extract spatial features.
* **Overfitting Prevention:** Implemented Batch Normalization and Dropout layers.
* **Optimization:** Used the Adam optimizer with categorical cross-entropy.
